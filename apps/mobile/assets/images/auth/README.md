# Sign-in logos

- Apple: https://cdn.simpleicons.org/apple (Simple Icons, CC0).
- Google: https://developers.google.com/static/identity/images/signin-assets.zip — logo extracted from the official light Android/Web icon button at 4× resolution. Google branding guidelines apply: https://developers.google.com/identity/branding-guidelines

These bundled assets require no network access when displaying the login sheet.
