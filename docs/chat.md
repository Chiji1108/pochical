# チャット

グループ・個別チャットの表示には `@kesha-antonov/react-native-chat` 5.0.1 を使用する。
メッセージ、未読数、既読位置、入力中の状態は引き続き Convex が管理する。

## 実装の分担

- `src/components/chat/chat-view.tsx`: ライブラリへの接続、テーマ、送信と失敗時の入力復元。
- `src/components/chat/chat-model.ts`: 保存データとグループイベントを表示用メッセージへ変換。
- `src/components/chat/invite-link-card.tsx`: アプリ固有の招待プレビュー。
- `src/components/chat/use-chat-read.ts`: 表示中かつアプリがアクティブなときに既読を更新。
- `src/components/chat/use-chat-typing.ts`: 入力中状態の同期。
- `convex/chat.ts` / `convex-lib/chatInteractions.ts`: 送信、返信先の検証、リアクションの更新権限。

ルートにある KeyboardProvider / GestureHandlerRootView を再利用する。
チャットの外側に KeyboardStickyView や別の KeyboardAvoidingView を追加しない。
キーボードの位置はライブラリの自動計測に任せる。

## 操作とデータ

長押しでコピー・返信・定番リアクションを選択できる。「＋」は既存のネイティブ絵文字シートを開く。
国旗・肌色・結合絵文字を含む単一の絵文字を受け付ける。スワイプでも返信できる。
入力欄では改行でき、送信ボタンで送信する。本文は最大1,000文字。
時刻と既読表示は吹き出しの外側に置く。送信中は「送信中」、既読になると「既読」または「既読 N」を表示する。
受信者の名前は同じ送信者・日付のまとまりの先頭で吹き出しの上に表示する。システム通知は時刻を本文の上に表示する。
入力値を直接制御し、送信開始と成功時に空にする。返信の名前・引用は専用の表示に揃える。
送信失敗時は本文と返信先を入力欄へ戻す。

返信先は同じ会話内の保存済みメッセージに限る。本文と送信者名の引用をサーバー側で保存する。
リアクションはユーザーごとに追加・解除し、会話の既読位置や未読件数には影響させない。
`reply` と `reactions` は、返信やリアクションのないメッセージでは省略する。
開発中のため旧チャットデータとの互換性は必須とせず、必要に応じて初期化できる。

## 検証

自動確認: `bun test`、`bun x tsc --noEmit`、`bun x ultracite check`。
チャットのテストでは返信の永続化、別会話への引用拒否、リアクションの権限・追加解除、既読人数、旧メッセージの変換を確認する。

iPhone 18 Pro / iOS 27 シミュレーターで Debug 開発ビルドの生成・インストール・起動を確認済み。
自分だけの確認用グループで、キーボード表示、複数行入力、送信と保存、URLのリンク化、
キーボード表示中に戻って開き直す操作を確認した。入力欄がキーボードに隠れないことも確認済み。

次は追加の実機・シミュレーター確認項目。長押し・スワイプは今回の操作ツールでは未確認。

- 個別チャットでのキーボード開閉、返信プレビュー表示中の入力欄位置。
- 長い履歴の追加読み込み、連続送信後のスクロール。
- 長押しとスワイプ、リアクションの追加・解除、URLと招待カードのタップ。
- 2端末で既読人数と未読バッジ、別画面表示中・バックグラウンド中の既読抑止。
- オフライン送信からの復帰、送信失敗時の本文・返信先の復元。

iOS・Android のバンドル生成は確認済み。
Web は対象外。

## シミュレーターの開発ビルド

Xcode 27 ではシミュレーターの画面操作に Device Hub
(`/Applications/Xcode.app/Contents/Applications/DeviceHub.app`) を使う。

```sh
bun x expo run:ios --device 9D91F5BA-437B-4D81-A87B-62B27B2B2365 --no-bundler
bun x expo start --dev-client --port 8082 --localhost
```

開発ビルドの「Enter URL manually」に `http://localhost:8082` を指定して接続する。
初回ビルドはネイティブ依存のコンパイルに時間がかかる。以後のJavaScript変更は再ビルド不要。

配置・返信表示・絵文字シートの追加修正は型チェックと自動テストを実施済み。
追加修正後の操作確認は Device Hub 操作ツールの `noWindowsAvailable` エラーで未完了。

初回読み込み中は空状態を表示しない。空状態は `listProps.ListEmptyComponent` に
View要素を直接渡す。react-native-chat 5.0.1 の `renderChatEmpty` ラッパーは
VirtualizedList が渡す反転補正の style を転送せず、逆さまに表示されるため使用しない。

メッセージ一覧は `isFlashListEnabled` を有効にし、導入済みの FlashList 2.3.2 を使用する。
降順データと `isInverted` を維持し、過去の履歴は従来どおり一覧の末尾で追加読み込みする。
日付チップは吹き出しの `surface` と分けて `surface-secondary`（グレー系）を使用する。
FlashList切り替え後のスクロール操作は実機確認が必要。

ライブラリの render コールバックにはフックを使うコンポーネントを直接渡さず、
JSX要素を返す関数を渡す。ライブラリが useMemo 内で直接呼び出す場合も
Reactコンポーネントの境界を維持する。`tests/chat-rendering.test.tsx` でこの条件を検証する。

返信引用は吹き出しの上部に名前と最大2行の本文を置き、細い横線で返信本文と区切る。
引用専用の背景・外枠は使用しない。引用をタップすると元のメッセージへ移動する。
元のメッセージが未読み込みなら履歴を追加取得し、全件取得しても見つからなければ案内する。

リアクションはアニメーションなしの標準表示を使用する。
